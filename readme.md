# Team Echo's Battleship

Requirements: Node.js, Visual Studio Code

# How to set up the frontend
1. Open Visual Studio Code
2. Open the frontend folder or do `cd frontend` on the terminal
3. Open the terminal and do `npm i` (MAKE SURE YOU ARE UP TO DATE WITH NODE.JS)
4. Once everything is installed, you can start it by typing `npm run dev`
5. Then you're done! Make any changes to the code in the src folder or index.html

# How to set up the backend
1. Open Visual Studio Code
2. Open the backend folder or do `cd backend` on the terminal
3. Open the terminal and do `npm i` (MAKE SURE YOU ARE UP TO DATE WITH NODE.JS)
4. Once everything is installed, you can start it by typing `npm start`
5. Then you're done! Make any changes to the code in index.js
